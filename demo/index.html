HTML Quick Setup & Integration Guide

hiinformer is a single, zero-setup library. Styles are automatically injected on-demand into your document. No external <link rel="stylesheet"> is required!

1. Browser HTML Script Tag (Zero Config)
<!-- Add script tag before </body> -->
<script src="path/to/dist/index.global.js"></script>

<script>
  const { useToast, useConfirm } = notify;

  // 1. Toast Notification
  useToast().add({
    status: 'success',
    title: 'Success!',
    message: 'Styles auto-injected in HTML.',
    position: 'top-end',
    timeout: 3
  });

  // 2. Confirm Dialog
  useConfirm().use({
    option: {
      header: 'Confirm Delete',
      message: 'Are you sure you want to delete?',
      acceptBtn: { label: 'Delete', color: 'danger' }
    },
    accept: () => console.log('Deleted!'),
    reject: () => console.log('Cancelled')
  });
</script>

CSS Theme & Color Customization Guidelines

You can easily customize all status colors, glass container fill, backdrop blurs, and corner radius by overriding CSS Custom Properties (Variables) in your CSS file or <style> block!

Live Theme Presets (Test Live Color Changes)
1. How to Override CSS Variables in HTML or CSS
/* Add to your stylesheet or <style> block */
:root {
  /* Brand Status Colors */
  --h-primary-color: #8b5cf6;
  --h-primary-glow: rgba(139, 92, 246, 0.35);
  
  --h-success-color: #10b981;
  --h-warning-color: #f59e0b;
  --h-danger-color: #ef4444;
  --h-info-color: #06b6d4;

  /* Glass Fill & Backdrop Blur */
  --h-toast-container-color: rgba(255, 255, 255, 0.75);
  --h-glass-blur: blur(16px) saturate(180%);
  --h-backdrop-color: rgba(15, 23, 42, 0.25);
  --h-backdrop-blur: blur(4px);

  /* Corner Radius & Dimensions */
  --h-border-radius: 16px;
  --h-dialog-box-width: 440px;
}
2. CSS Variables Reference List
  • --h-primary-color: Primary accent & default toast color
  • --h-success-color: Success notification & accept button color
  • --h-warning-color: Warning notification status color
  • --h-danger-color: Danger notification & confirm action color
  • --h-info-color: Info notification status color
  • --h-toast-container-color: Glass card fill background color
  • --h-glass-blur: Toast backdrop blur filter
  • --h-backdrop-blur: Confirm modal backdrop overlay blur
  • --h-border-radius: Glass card corner radius (default: 16px)
